# Later rows guarantee a density floor

Extract the ZIP and open index.html. The explorer works offline. Select an atom, rotate the weighted density entries, and compare all rows with those after the last low row.

Rows one and two fall below the threshold at A and B, respectively. Every row meets the threshold at C. The displayed floors use only weights after the last low row. The third display row groups all rows from index three onward into their exact weighted average.
