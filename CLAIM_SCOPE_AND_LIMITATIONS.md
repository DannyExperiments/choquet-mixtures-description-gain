# Claim scope

The main theorem uses subprobabilities on the source's Polish/Borel measurable mixture model. The reference Q, sampling measure P and every candidate share one σ-finite dominator. The candidate class is closed under countable mixtures. Undefined gains contribute negative infinity. The equality concerns the entire extended supremum.

The finite-convex result instead assumes P is absolutely continuous with respect to Q and the class contains a member of finite gain. Examples show failure when the finite-convex class has no anchor and when the countably convex class has no common dominator. The paper gives supremum invariance. Existence of an optimizing measure and implications for general unbounded measure families are outside the claim.
